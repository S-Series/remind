# Guided Warp 60

사용자가 지정한 전환 순서에 맞춘 **60장·60fps·1초** 시퀀스입니다. `Frames/guided_warp_000.png`부터 `guided_warp_059.png`까지 이름순으로 재생하세요. 전부 1672×941의 투명 PNG입니다.

| 프레임(0부터) | 구성 |
| --- | --- |
| 000–016 | 화면 중앙의 얇은 빛 3가닥에서 시작해 빛가닥이 순차적으로 늘어납니다. |
| 017–031 | 작은 조각 10개가 2·3·2·3개 묶음으로 등장해 바깥으로 이동합니다. 빛가닥도 계속 추가됩니다. |
| 032–039 | 별도 생성한 중간 밀도 장면으로 점진적으로 이어집니다. |
| 040–046 | 제공된 기준 이미지에 가까워집니다. |
| **047** | 제공된 `codex-clipboard-d48c8555-3b9d-46db-894b-909dba553cb5.png`를 **그대로 복사한 프레임**입니다. 60장 중 약 80% 지점입니다. |
| 048–059 | 빛가닥 수와 밀도가 점차 줄고 조각이 밖으로 이동합니다. 끝에는 소수의 가는 빛만 남습니다. |

`Sprites/Rays/`의 빛줄기 4종, `Sprites/Shards/`의 작은 조각 4종, `Keyframes/mid_density.png`는 내장 이미지 생성 기능으로 만든 시각 소재입니다. 그 소재의 등장 시간·위치·회전·알파를 연속 보간해 각 프레임을 합성했습니다. 조각이 주제가 되지 않도록 빛을 중심으로 두었습니다. 첨부된 기준 이미지는 047번에서만 완전한 원본 형태로 표시됩니다.

이 폴더는 이전의 `WarpFrames`와 `SoftWarpFrames`를 대체하는 새 버전입니다. Unity에서는 `Frames`의 60장만 Animation에 넣고 샘플레이트를 60으로 설정하세요. Sprite Import 설정은 포함되어 있습니다. 실제 Unity 재생과 셰이더 적용은 아직 확인하지 않았습니다.
