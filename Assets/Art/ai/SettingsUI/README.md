# ReMind Settings UI 이미지 생성 에셋

첨부된 설정 화면을 참고해 이미지 생성 도구로 만든 투명 RGBA PNG 묶음이다. 생성된 투명 시트를 아이콘·선·컨테이너 단위로 기계적으로 분리했다. Python이나 벡터 코드로 그림을 그리지 않았다.

| 폴더 | 수량 | 내용 |
| --- | ---: | --- |
| `Icons` | 17 | 사이드바 메뉴 8종, 오디오·버튼 조작 기호 8종, 홈 화면에서 재사용한 나침반 |
| `Lines` | 8 | 구분선, 코너 장식, 별·다이아몬드·점 마커, 제목 밑줄 |
| `Containers` | 14 | 설정 창·사이드바·선택 탭·그림 프레임·하단 버튼, 슬라이더·선택 그룹·드롭다운·토글 |

모든 PNG는 Unity `Sprite (2D and UI)`로 설정했다. 배경 건물과 수면, 오른쪽 카드 속 삽화, 로고 글자 및 모든 UI 문구는 포함하지 않는다. `header_compass`는 이전에 직접 생성한 `HomeUI/Icons/logo_compass`를 재사용했다.

슬라이더는 `slider_track` + `slider_fill` + `slider_thumb`로 조합한다. Hit Sound는 `hit_sound_group` 위에 `hit_sound_selected`를 겹친다. 드롭다운 화살표는 `Icons/dropdown_chevron`을 필드 위에 놓는다. 토글은 켜짐·꺼짐 스프라이트가 별도다. 큰 유리 패널에는 그림과 글자를 Unity UI 요소로 별도 배치한다.

생성 지시의 공통 기준: "첨부된 ReMind 설정 화면의 작은 은백색 아이콘, 천문학적 선 장식, 남청색 유리 패널과 연보라색 선택 상태를 각각 독립 UI 스프라이트로 만들 것. 배경 장면과 글자는 제외하고 실제 투명 배경을 유지할 것." 아이콘·선·컨테이너 시트를 직접 생성한 뒤 칸별 파일로 분리했다. 생성 과정에서 더해진 은청색 가장자리 빛은 PNG에 포함되어 있다. Unity에서 추가 발광을 쓰려면 스프라이트 알파를 셰이더 마스크로 사용할 수 있다.
