# ReMind Home UI 이미지 생성 에셋

첨부된 ReMind 홈 화면을 참고해 **이미지 생성 도구로 직접 만든** 투명 PNG 묶음이다. 작은 UI 요소를 개별 스프라이트로 쓰도록 생성 시트를 기계적으로 분리하고 투명 여백만 잘랐다. 파이썬이나 벡터 코드로 그림을 그리지 않았다.

| 폴더 | 파일 수 | 구성 |
| --- | ---: | --- |
| `Icons` | 19 | 로고 나침반, 하단 메뉴 5종, 재생·설정·종료, 상태 표시, 꽃·나비·별 |
| `Lines` | 12 | 선, 링, 모서리, 별·점·다이아몬드 마커, 선택 밑줄 |
| `Containers` | 6 | 앨범 원형·사각 프레임, 플레이어 패널, 유리 패널, 원형 버튼 2종 |

모든 파일은 투명 RGBA PNG이며 Unity `Sprite (2D and UI)`로 설정했다. 원본 장면의 배경, 인물 일러스트, 글자, 앨범아트는 포함하지 않는다. 이미지 생성 특유의 은청색 빛 가장자리가 일부 에셋에 들어 있다. Unity에서 발광을 별도로 제어하려면 스프라이트의 알파를 마스크로 사용하고 셰이더에서 색·강도를 조절한다.

`glass_panel`과 `now_playing_panel`은 고정 비율 장식 이미지다. 현재 메타데이터에 9-slice Border를 설정하지 않았다. 텍스트나 앨범아트를 올릴 때는 별도 UI 요소로 겹친다.

생성 지시의 공통 기준: "첨부된 ReMind 홈 화면의 아이콘·선·프레임을 각각 분리하여, 남청색과 은백색의 얇은 빛, 천문기구·별·유리 반사를 살린 단독 Unity UI 스프라이트로 만들 것. 글자와 장면 배경은 제외하고 실제 투명 배경을 유지할 것." 주요 메뉴 5종과 로고는 각각 단독 생성했고, 작은 조작 아이콘·선·컨테이너는 종류별 투명 시트로 생성 후 칸별로 분리했다.
