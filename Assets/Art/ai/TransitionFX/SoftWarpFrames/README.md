# Soft Warp — 60fps sequence

`Frames/soft_warp_000.png`부터 `soft_warp_035.png`까지 **36장의 1672×941 투명 PNG**를 순서대로 재생합니다. 60fps에서 0.6초입니다. 시작은 작은 중심광, 중간은 은은한 은빛 광선의 확산, 끝은 중심이 비고 빛이 화면 밖으로 사라지는 흐름입니다.

`Sources/soft_light_master.png`와 `Sources/soft_light_exit.png`는 내장 이미지 생성 기능으로 만든 원본입니다. 이전의 수정 파편 효과를 스타일·방향 참조로만 사용하고, 수정 조각과 강한 폭발감은 제거하도록 요청했습니다. 긴 가는 빛줄기, 곡선형 반사광, 작은 별빛과 투명한 여백에 집중했습니다. 36프레임은 두 생성 이미지의 중심 기준 확대, 알파 보간, 이탈 상태의 교차 전환으로 구성했습니다. 따라서 프레임마다 도형이 새로 그려져 튀는 현상 없이 같은 광선이 이어집니다.

Unity에서는 36개 PNG를 Sprite로 가져와 순서대로 표시하고 샘플레이트를 60으로 설정하세요. 마지막 프레임은 완전 투명하므로 다음 장면이나 별도의 흰색 페이드로 이어갈 수 있습니다. `Sources/`는 재조정용 원본이며 재생 목록에는 넣지 않습니다. 실제 Unity 재생, Canvas 크기 및 셰이더 결과는 아직 확인하지 않았습니다.
