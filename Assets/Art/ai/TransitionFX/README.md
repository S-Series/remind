# ReMind transition FX

제공된 8단계 전환 콘티(`codex-clipboard-784c8dc5-7286-4896-9502-29f31c7f253c.png`)를 참고해 이미지 생성 기능으로 만든 투명 PNG 레이어입니다. 원본 콘티를 잘라낸 것이 아니라 분위기와 형태를 재제작했습니다. 두 장의 생성 시트는 칸별로 기계적으로 분리했으며, 나머지 두 장은 화면 오버레이 원본입니다.

## 파일

`Sprites/`의 8개 스프라이트는 모두 768×512로, 같은 중앙 피벗에 포개기 쉽습니다.

| 파일 | 용도 |
| --- | --- |
| `star_seed.png` | 01: 첫 빛점 |
| `compass_star.png` | 02–04: 성장하는 중심 별 |
| `celestial_ring.png` | 02–04: 원형 천문 고리 |
| `orbit_pair.png` | 03–04: 회전하는 타원 궤도 |
| `spark_point.png` | 02–04: 작은 반짝임, 복제·산포 가능 |
| `crystal_shard.png` | 04–05: 큰 빛 파편, 복제·회전 가능 |
| `orbit_ribbon.png` | 04: 유선형 빛 궤적 |
| `shard_scatter.png` | 04–05: 여러 파편과 별가루 |

`Overlays/`의 `warp_tunnel.png`는 05의 방사형 이동 효과, `fade_horizon.png`는 06–07의 희미한 수평 빛결입니다. 전체 화면에 맞춰 배치하고 알파와 크기를 애니메이션하세요. 발광이 필요하면 Unity에서 Additive 계열 머티리얼 또는 Bloom을 시험할 수 있습니다.

`WarpFrames/`에는 이 방사형 이동 효과의 **6프레임 시퀀스**가 있습니다. 모두 1672×941 투명 PNG이며 동일한 캔버스 중앙을 기준으로 그렸습니다. 파일명 순서대로 재생하면 작은 중심 빛 → 확산 → 전체 화면 → 가장자리로 이탈하는 흐름입니다. 예를 들어 8–12fps에서 시작해 보고, 더 부드러운 움직임이 필요하면 Unity에서 인접 프레임을 짧게 크로스페이드하거나 크기를 보간하세요. 각 프레임은 이미지 생성으로 개별 편집되었으므로 파편의 픽셀 위치가 완전히 고정된 시뮬레이션은 아닙니다. `warp_05_full.png`는 기존 `Overlays/warp_tunnel.png`와 같은 전체 확산 이미지입니다.

`SoftWarpFrames/`는 이전 요청에 맞춰 만든 **60fps·36프레임의 부드러운 빛 중심 버전**입니다. 수정 조각 대신 가는 은빛 광선과 잔별을 사용하며, 0.6초 동안 중앙에서 퍼졌다가 화면 밖으로 사라집니다. 자세한 내용은 해당 폴더의 `README.md`에 있습니다.

`GuidedWarp60/`는 최신 가이드에 맞춘 **60fps·60프레임의 1초 버전**입니다. 실제 전환에는 이 버전을 우선 사용하세요. 3가닥의 빛에서 시작해 가닥 수가 늘고, 작은 조각 10개가 묶음으로 나와 이동합니다. 제공된 원본 이미지는 47번 프레임에 그대로 들어가고 이후 빛가닥이 줄어듭니다. 자세한 내용은 해당 폴더의 `README.md`에 있습니다.

## 조합 순서

1. 어두운 화면 중앙에서 `star_seed`의 크기와 알파를 올립니다.
2. `compass_star`와 `celestial_ring`을 나타내고 고리를 천천히 회전합니다.
3. `orbit_pair`, 복제한 `spark_point`를 추가합니다.
4. `orbit_ribbon`, `crystal_shard`, `shard_scatter`를 바깥쪽으로 움직이며 중심을 밝힙니다.
5. `warp_tunnel`을 확대·페이드하여 앞으로 이동하는 느낌을 만듭니다.
6. Unity의 단색 UI Image나 셰이더로 화면을 연한 흰색으로 페이드하고 `fade_horizon`을 얹습니다.
7. `ReMind` 제목과 부제는 TextMeshPro로 표시합니다. 정확한 문자 형태와 로컬라이징을 위해 그림 안에 굽지 않았습니다.
8. 제목과 빛결을 페이드하고 다음 장면으로 전환합니다.

이미지 생성 프롬프트는 기준 이미지의 은빛·남청색·수정·천문 궤도 스타일을 지정하고, 각각 중심 별/고리, 파편/빛 장식, 방사형 이동 오버레이, 흰 페이드의 수평 빛결을 요청했습니다. 모든 결과는 투명 배경으로 생성했습니다. 실제 Unity Canvas 배치, Blend Mode, Bloom 및 재생 타이밍은 검증하지 않았습니다.
