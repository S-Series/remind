# ReMind Result UI 에셋

첨부된 RESULT 화면을 참고해 이미지 생성 도구로 제작한 투명 PNG 묶음이다. 화면 배경, 인물 그림, 텍스트, 재킷 이미지는 포함하지 않는다. 생성된 시트의 요소를 파일별로 분리했으며, 아이콘 형태를 Python 등으로 그리지 않았다.

| 기존 종류 | 수량 | 주요 구성 |
| --- | ---: | --- |
| 아이콘 | 9 | 금빛 S, S+궤도 조합, 재시도·다음·곡 목록, 보상 수정·나비, 꽃·별 |
| 선·장식 | 9 | 금빛 랭크 궤도, 가로 구분선, 기록 밑줄, 정확도 트랙·채움, 마커 |
| 프레임·패널 | 12 | 곡 정보·점수·판정·정확도 패널, 보상·기억 조각 프레임, 재킷·난이도·버튼 프레임, 빈 유리 패널 |

모든 PNG는 `ResultUI` 바로 아래에 둔다. `rank_s_glyph.png`와 `rank_orbit_gold.png`는 각각 독립 배치하거나 애니메이션할 수 있다. `rank_s_orbit.png`는 합쳐진 결과를 바로 쓰고 싶을 때의 선택지다. 패널에 들어간 선이나 장식을 별도로 조절하려면 `empty_glass_panel.png`와 선 장식을 조합한다.

점수 나침반과 Bootstrap에서도 쓰는 선 장식은 `../CommonUI/`에 둔다.

PNG는 RGBA이고 `.meta`는 Unity `Sprite (2D and UI)`로 설정했다. Unity Editor에서 실제 표시와 셰이더 적용은 아직 확인하지 않았다.

## 분리형 랭크 배지 (200×200)

등급 `D`, `C`, `B`, `A`, `A+`, `AA`, `AA+`, `S`, `S+`마다
`rank_<grade>_border_200.png`와 `rank_<grade>_glyph_200.png`를 하나씩
새로 생성했다. `+`가 포함된 등급은 파일명에 `a_plus`, `aa_plus`,
`s_plus`를 사용한다. 총 18개의 독립 RGBA Sprite다.

첨부된 9등급 시트의 별·달·날개 장식을 참고해 테두리를, 중앙의
세리프 글자 형태를 참고해 글자만 이미지 생성 도구로 각각 제작했다.
글자는 돌출된 3D 표현을 줄이고 은백색 평면 표현으로 다시 생성했다.
기존 이미지에서 글자나 테두리를 지우거나 잘라내지 않았다. 생성
결과는 투명도를 보존한 채 200×200 캔버스에 맞춰 축소·중앙 정렬했다.

Unity UI에서는 같은 등급의 `glyph`를 `border` 위에 겹쳐 놓는다.
궤도가 글자 앞을 지나가야 하는 연출에는 `border`의 표시 순서를
위로 바꿀 수 있다. 기존 `rank_s_orbit.png`, `rank_s_glyph.png`,
`rank_orbit_gold.png`는 수정하지 않았다.
