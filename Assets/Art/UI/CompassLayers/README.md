# Compass gem layers

The seven transparent PNGs in this folder were generated from the supplied compass image and sized onto matching 1254 × 1254 canvases. All sprites use a centered pivot. Place their UI Images in the same RectTransform size and position to assemble the symbol.

Back to front:

1. `orbit_halo.png` — soft inner halo (optional)
2. `orbit_descending.png` — upper left to lower right orbit
3. `orbit_ascending.png` — lower left to upper right orbit
4. `gem_diagonal_x.png` — four diagonal crystal points
5. `gem_horizontal.png` — long horizontal crystal
6. `gem_vertical.png` — long vertical crystal
7. `gem_center.png` — small central crystal

The orbital layers can rotate independently. These are visual reconstructions from the reference, so they are not pixel-identical masks of the source. Unity Sprite import settings and unique `.meta` files are included.
